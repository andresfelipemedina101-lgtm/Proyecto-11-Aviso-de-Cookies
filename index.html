¿Qué es el DOM?

El DOM es la representación de la página web que JavaScript puede leer y modificar.

Eventos en JavaScript

Los eventos permiten ejecutar código cuando el usuario hace clic, escribe o mueve el mouse.

¿Qué es LocalStorage?

LocalStorage permite guardar información en el navegador para usarla en otra visita.
